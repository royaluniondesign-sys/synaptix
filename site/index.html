How it works

A small agent on your machine. A cockpit wherever you are.

Termora is a local agent plus a web interface. Your phone never talks to a fake shell: it streams authenticated input and output to real terminal sessions on your computer.

Run the agent

Start Termora on a Mac or Linux machine. It opens real PTY sessions and keeps them alive with tmux when tmux is installed.

Pair a device

Scan the QR code from your phone or open the address in a browser. A pairing token is exchanged for a session token.

Run your agents

Open terminals, start CLI coding agents, and watch what each one is doing from a single screen.

Features

What it does today.

Everything here exists in the code and is covered by tests. What does not exist yet is listed further down.

>_

Real terminals

Sessions are real PTYs streamed over WebSocket. Create, rename, close, reconnect and resume them.

QR

Secure pairing

QR or token pairing, JWT session tokens, and rate-limited authentication endpoints.

AI

Agent registry

Built-in profiles for Claude Code, Codex, OpenCode, Hermes, Aider, Gemini CLI and Goose. Agents start as argument lists, never through a shell. Launching them is off unless you set TERMORA_ENABLE_AGENT_SPAWN=1.

~

Status from output

A heuristic reads an agent's terminal output and labels it idle, running, editing, testing, waiting, failed or done. It is a guess from text, not a protocol the agents speak.

Y

Worktree fan-out

Start the same task in several isolated git worktrees, one session per worktree.

[ ]

Desktop shell

An Electron app that bundles the agent and the interface into one installable package.

Install

Run it from source.

Needs Node.js 20 or newer on macOS or Linux.

git clone https://github.com/royaluniondesign-sys/termora.git
cd termora
npm install
TUNNEL=local npm run dev
  • The terminal prints a QR code and an address. Open it from your phone or another browser on the same network.
  • Stop it with Ctrl+C.
  • Windows: only the CI-built package exists for now.

Read this before you run it without TUNNEL=local.

By default Termora tries to open a public tunnel (ngrok, then SSH through localhost.run) so your phone can reach it from outside your network. Traffic then passes through that provider. Access is protected by a pairing token, but the address is public.

TUNNEL=local keeps it on your own network.

FAQ

Questions.

Is it free?

Termora is open source under the MIT license. There is no paid plan today.

Where does my data go?

Termora runs on your machine. There is no Termora server, account or sign-up, and the application code contains no analytics or telemetry. This page loads no scripts, fonts or trackers from other sites. The one exception to "stays on your machine" is the optional public tunnel described under Install.

Why is there no download button?

The desktop packages are unsigned, not notarized, and have not been published as a release. Until they are, running from source is the honest way to try it.

Which agents does it work with?

It launches CLI agents that you have installed yourself: Claude Code, Codex, OpenCode, Hermes, Aider, Gemini CLI and Goose, or any command you add. Termora checks that the command exists on your PATH. It does not bundle or install them.

Does it work on Windows?

A Windows x64 installer is built and started automatically, but nobody has used it on a real Windows machine yet. From-source support covers macOS and Linux.

How do I report a problem?

Open an issue on GitHub with your operating system, Node.js version and what you did.

Help us test it

Run it on your machine. Tell us what broke.

The most useful thing right now is someone using Termora for real work and reporting what gets in the way.
