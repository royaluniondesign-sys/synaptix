Your machine, in your hands.

Termora streams the real terminals and coding agents running on your own computer to a browser or your phone. Nothing runs in a cloud workspace; the shell is yours.

What it does today

  • Real terminals. Sessions are real PTYs streamed over WebSocket, with tmux persistence when tmux is available. Pair a phone or browser by scanning a QR code.
  • An agent registry. Built-in profiles for Claude Code, Codex, OpenCode, Hermes, Aider, Gemini CLI and Goose, plus custom ones. Agents start as argument lists, never through a shell, and launching them is off unless you set TERMORA_ENABLE_AGENT_SPAWN=1.
  • Status from output. A heuristic reads an agent's terminal output and labels it idle, running, editing, testing, waiting, failed or done. It is a guess from text, not a protocol the agents speak.
  • Git worktree fan-out. Start the same task in several isolated worktrees.
  • A desktop shell. An Electron app that bundles the agent and the interface.

What is not done

Desktop builds

  • Linux (AppImage), macOS (Apple Silicon) and Windows (x64) packages build in CI and start correctly in an automated test.
  • They are unsigned, not notarized, and not published as a release. There is no download button because there is nothing to download yet.
  • No macOS Intel build.
  • A person has not yet installed and used them on a Mac or a Windows PC.

Product

  • SSH and SFTP to other machines are not finished.
  • The native mobile app is a scaffold; use the browser or the installable web app.
  • No accounts, no relay service, no paid plan.
  • Few people have used it. Expect rough edges.

The full list, kept in step with the code, is in the status document and the roadmap.

Install from source

Needs Node.js 20 or newer on macOS or Linux.

git clone https://github.com/royaluniondesign-sys/termora.git
cd termora
npm install
TUNNEL=local npm run dev

The terminal prints a QR code and an address. Open it from your phone or another browser on the same network.

Windows: only the CI-built desktop package exists, and WSL support is not documented yet.

Privacy

  • Termora runs on your machine. There is no Termora server, account or sign-up.
  • The application code contains no analytics or telemetry. This page loads no scripts, fonts or trackers from other sites.
  • Without TUNNEL=local, Termora tries to open a public tunnel (ngrok, then SSH through localhost.run) so your phone can reach it from outside your network. Traffic then passes through that provider. Access is protected by a pairing token, but the address is public. Set TUNNEL=local to stay on your own network.

Help us test it

The most useful thing right now is someone running it on their own machine and telling us what broke. Open an issue on GitHub with your OS, Node version and what you did.
